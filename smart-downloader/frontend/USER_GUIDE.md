# 智下载 SmartDownloader - 用户操作手册

**版本**: v1.0  
**发布日期**: 2026-03-24

---

## 1. 快速入门

### 1.1 登录系统

1. 打开浏览器访问系统地址
2. 输入组织 ID、用户名和密码
3. 点击"登录"按钮

---

## 2. 组织管理

### 2.1 创建组织

1. 进入"组织管理"页面
2. 点击"新建组织"按钮
3. 输入组织名称
4. 点击"确定"

### 2.2 编辑组织

1. 在组织列表中找到目标组织
2. 点击"编辑"按钮
3. 修改组织信息
4. 点击"确定"

### 2.3 删除组织

1. 在组织列表中找到目标组织
2. 点击"删除"按钮
3. 确认删除

---

## 3. 业务系统配置

### 3.1 添加业务系统

1. 进入"业务系统"页面
2. 点击"新建系统"按钮
3. 填写系统信息：
   - 系统名称
   - 系统 URL
   - 系统类型 (财务/ERP/CRM/自定义)
4. 配置登录信息

### 3.2 配置凭证

1. 在系统详情中点击"配置凭证"
2. 输入用户名和密码
3. 选择验证方式
4. 点击"测试连接"验证

---

## 4. 流程管理

### 4.1 文字描述创建流程

1. 进入"流程管理"页面
2. 点击"创建流程"
3. 选择"文字描述"标签
4. 输入流程描述，例如：
   ```
   登录后点击报表菜单，选择日报，点击下载按钮，保存到指定目录
   ```
5. 点击"生成流程"
6. 预览并确认 YAML 配置
7. 保存流程

### 4.2 截图标注创建流程

1. 进入"流程管理"页面
2. 点击"创建流程"
3. 选择"截图生成"标签
4. 上传页面截图
5. 框选操作区域
6. 选择操作类型 (点击/输入/下载)
7. 点击"生成流程"
8. 保存流程

### 4.3 画布编辑流程

1. 在流程列表点击目标流程
2. 进入画布编辑器
3. 从节点库拖拽节点到画布
4. 连接节点定义流程
5. 点击节点编辑属性
6. 保存流程

---

## 5. 任务执行

### 5.1 立即执行

1. 进入"任务管理"页面
2. 找到目标流程
3. 点击"执行"按钮
4. 查看执行进度和日志

### 5.2 定时执行

1. 创建任务时配置 Cron 表达式
2. 系统自动按时执行

### 5.3 查看执行日志

1. 在任务列表点击目标任务
2. 查看执行日志时间线
3. 查看截图记录

---

## 6. 文件管理

### 6.1 查看下载文件

1. 进入"文件管理"页面
2. 查看文件列表

### 6.2 下载文件

1. 在文件列表找到目标文件
2. 点击"下载"按钮

### 6.3 预览文件

1. 在文件列表找到目标文件
2. 点击"预览"按钮

### 6.4 删除文件

1. 在文件列表找到目标文件
2. 点击"删除"按钮
3. 确认删除

---

## 7. 常见问题

### Q: 忘记密码怎么办？
A: 联系组织管理员重置密码

### Q: 任务执行失败怎么办？
A: 查看执行日志，根据错误信息排查问题

### Q: 如何查看任务执行进度？
A: 在"任务管理"页面查看实时进度条

### Q: 支持哪些浏览器？
A: Chrome 120+、Edge 120+、Firefox 115+
