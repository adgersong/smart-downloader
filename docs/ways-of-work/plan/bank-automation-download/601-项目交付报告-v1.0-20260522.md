## 🚀 部署说明

### 快速启动

```bash
# 1. 进入项目目录
cd smart-downloader

# 2. 复制环境配置
cp .env.example .env

# 3. 编辑 .env 配置必要参数
vim .env

# 4. 启动服务
./start.sh              # 基础模式
./start.sh --with-ai    # AI 模式

# 5. 访问应用
前端：http://localhost:3000
API 文档：http://localhost:8000/api/docs
```

### 生产环境部署

```bash
# 1. 修改 docker-compose.yml 启用 PostgreSQL
# 2. 配置 SECRET_KEY 和 ENCRYPTION_KEY
# 3. 配置通知服务 webhook
# 4. 部署到服务器
docker-compose up -d --profile production

# 5. 初始化数据库
./migrate.sh init
```
