## 1. 设计概述

### 1.1 设计目标

打造一款**科技感、简洁大气、高效易用**的企业级浏览器自动化下载管理平台，对标互联网大厂设计水准 (阿里 Ant Design/字节 Design/腾讯 TDeng)，基于 Ant Design Pro 5.x 设计语言，提供一致、流畅的用户体验。

### 1.2 设计原则

| 原则 | 说明 | 大厂参考 |
|------|------|----------|
| **科技感** | 深色主题、渐变效果、玻璃拟态、精致动效 | 阿里/字节后台 |
| **简洁大气** | 留白充足、层次清晰、去除冗余 | 苹果/极简主义 |
| **一致性** | 遵循 Ant Design 5.x 设计规范，保持界面元素、交互行为统一 | Ant Design |
| **高效性** | 核心操作 3 步内完成，减少用户认知负担 | 字节效率工具 |
| **可视化** | 复杂流程图形化展示 (LangGraph 画布)，直观易懂 | 阿里 DataV |
| **容错性** | 操作可撤销、可恢复，错误提示清晰可理解 | 腾讯 CDC |
| **响应性** | 界面响应 < 200ms，加载状态明确反馈 | 大厂标准 |

### 1.3 设计语言关键词

```
科技感      简洁       大气       专业       高效
 │          │          │          │          │
 ▼          ▼          ▼          ▼          ▼
深色主题    留白       大卡片     数据可视    一键操作
渐变效果    层次       宽屏布局   动效反馈    智能提示
玻璃拟态    聚焦       精致       权威感     流畅
```

### 1.4 目标用户

| 用户角色 | 使用场景 | 设计重点 |
|----------|----------|----------|
| 系统管理员 | 管理组织、监控系统 | 全局视图、数据仪表板、科技感 |
| 组织管理员 | 配置流程、管理凭证 | 可视化编辑、安全输入、简洁 |
| 业务操作员 | 执行任务、下载文件 | 一键操作、进度可见、高效 |
| 审计员 | 查看日志、审查操作 | 搜索过滤、导出功能、专业 |

```
Radius-0: 0px       (表格、分割线、严肃元素)

### 2.6 渐变效果 (科技感核心)

```

- Primary Gradient: linear-gradient(135deg, #1677FF 0%, #69B1FF 100%)
- Success Gradient: linear-gradient(135deg, #52C41A 0%, #95DE64 100%)
- Warning Gradient: linear-gradient(135deg, #FAAD14 0%, #FFC53D 100%)
- Error Gradient: linear-gradient(135deg, #FF4D4F 0%, #FF7875 100%)

## 7. 动效设计

### 7.1 过渡动画

```css
/* 页面切换 */
.page-transition {
  transition: opacity 0.2s ease-in-out;
}

/* 卡片悬浮 */
.card-hover {
  transition: transform 0.2s, box-shadow 0.2s;
}
.card-hover:hover {
  transform: translateY(-2px);
  box-shadow: var(--shadow-2);
}

/* 按钮点击 */
.button-click {
  transition: transform 0.1s;
}
.button-click:active {
  transform: scale(0.98);
}
```

### 7.2 画布动画

| 动画 | 说明 | 时长 |
|------|------|------|
| 节点拖拽 | 跟随鼠标，阴影悬浮 | 实时 |
| 连线创建 | 贝塞尔曲线绘制 | 200ms |
| 执行流向 | 虚线流动动画 | 持续 |
| 状态变更 | 颜色渐变 + 图标切换 | 300ms |
| 画布缩放 | 平滑缩放聚焦 | 200ms |

### 7.3 反馈动画

```
成功: ✓ 图标缩放弹跳 (300ms)
      绿色波纹扩散

错误: ✗ 图标左右摇晃 (300ms)
      红色闪烁

加载: ⟳ 旋转 (持续)
      1s/圈，线性
```
