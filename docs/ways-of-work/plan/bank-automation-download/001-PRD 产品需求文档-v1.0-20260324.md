## 1. 产品概述

### 1.1 产品名称

**智下载 (SmartDownloader)** - 智能浏览器自动化下载系统

### 1.2 产品定位

一款面向企业组织的通用浏览器自动化下载解决方案，支持多业务系统、多财务系统的自动化数据采集与下载，通过 AI 驱动的语义理解和拟人化行为模拟，实现零代码配置的自动化工作流。

### 1.3 技术架构

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| **前端** | Ant Design Pro | 企业级管理后台，支持多租户组织管理 |
| **后端** | FastAPI | 高性能 Python API 服务 |
| **数据库** | SQLite | 轻量级本地存储 (支持后续迁移 PostgreSQL) |
| **工作流引擎** | LangGraph | 状态机驱动的多步骤自动化编排 |
| **浏览器自动化** | Playwright | 跨浏览器自动化控制 |
| **视觉理解** | Qwen VL (Ollama) | 本地 VLM 模型，语义理解页面内容 |
| **配置格式** | YAML | 可读性强的自动化流程配置 |

## 2. 目标与价值

### 2.1 问题陈述

企业在日常运营中需要从多个业务系统和财务系统定期下载数据报表，当前存在以下痛点：

1. **重复劳动**: 财务人员每天花费 1-2 小时手动登录多个系统下载报表
2. **易出错**: 人工操作容易遗漏、下载错误版本或过期数据
3. **反爬限制**: 传统自动化工具容易被网站检测并封锁
4. **维护成本高**: 页面结构变化导致自动化脚本失效，需要频繁调整
5. **缺乏统一管理**: 各组织/部门的自动化需求分散，无法集中管控

### 2.2 解决方案

智下载通过以下方式解决上述问题：

1. **拟人化操作**: 模拟真实用户的鼠标移动、键盘输入、随机延迟等行为模式
2. **AI 语义理解**: 使用 VLM 理解页面语义，不依赖固定 DOM 选择器，页面微调不影响自动化
3. **零代码配置**: 支持文字描述或截图标注的方式定义自动化流程
4. **多租户管理**: 按组织隔离配置和数据，支持统一管理和独立运行
5. **反检测机制**: 移除 webdriver 特征、隐藏自动化签名、动态指纹模拟

### 2.3 预期影响

| 指标 | 当前状态 | 目标状态 | 提升幅度 |
|------|----------|----------|----------|
| 单报表下载耗时 | 5-10 分钟 (人工) | 1-2 分钟 (自动) | 80% 效率提升 |
| 操作错误率 | ~5% | <0.5% | 90% 错误减少 |
| 人力成本 | 2 小时/天/人 | 10 分钟/天/人 | 90% 成本降低 |
| 自动化成功率 | N/A | >95% | - |
| 页面变更适应时间 | 1-2 小时 (改脚本) | <5 分钟 (自动适应) | 95% 时间节省 |

## 3. 用户角色

### 3.1 系统管理员 (System Admin)

- **职责**: 管理平台全局设置、组织账号、系统监控
- **需求**: 统一视图管理所有组织、查看系统健康状态、配置全局策略

### 3.2 组织管理员 (Organization Admin)

- **职责**: 管理本组织的自动化配置、凭证、执行计划
- **需求**: 配置业务流程、管理账号凭证、查看执行日志、设置调度计划

### 3.3 业务操作员 (Business Operator)

- **职责**: 执行自动化任务、下载报表、处理异常
- **需求**: 一键执行任务、查看下载状态、接收通知、处理验证码等异常

### 3.4 审计员 (Auditor)

- **职责**: 审查自动化操作记录、确保合规
- **需求**: 查看操作日志、下载记录、异常处理记录

## 7. 验收标准

### 7.1 核心流程验收

| 场景 | Given | When | Then |
|------|-------|------|------|
| 组织创建 | 系统管理员登录 | 创建新组织并配置基本信息 | 组织创建成功，可切换到该组织空间 |
| 系统配置 | 组织管理员在组织空间 | 添加一个财务系统配置 (URL/凭证) | 系统配置保存成功，可测试连接 |
| 流程定义 - 文字描述 | 组织管理员输入文字描述 | 描述"登录后点击下载报表按钮" | AI 生成正确的 YAML 配置，可预览和编辑 |
| 流程定义 - 截图标注 | 组织管理员上传截图并框选 | 框选按钮并标注"点击" | 生成对应点击动作的 YAML 配置 |
| 流程定义 - 无标注截图 | 组织管理员上传页面无标注 | AI 自动分析页面结构 | 识别出可操作元素并生成建议流程 |
| 流程定义 - 有标注截图 | 组织管理员上传带标注截图 | AI 识别框选/箭头等标注 | 解析标注意图并生成对应流程 |
| 任务执行 | 业务操作员 | 执行配置好的下载任务 | 任务成功执行，文件下载到指定位置 |
| 异常处理 | 任务执行中遇到验证码 | 系统暂停并发送通知 | 收到通知，人工处理后任务继续 |

### 9.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Qwen VL 识别准确率不足 | 自动化失败率升高 | 保留传统选择器作为备选方案 |
| 目标系统反爬升级 | 可能被检测封锁 | 持续更新反检测策略，保持特征库更新 |
| LangGraph 状态机复杂度 | 复杂流程难以调试 | 提供可视化流程调试工具 |

### 9.2 外部依赖

| 依赖 | 用途 | 备选方案 |
|------|------|----------|
| Ollama | 本地运行 Qwen VL 模型 | 可切换到其他 VLM 服务 |
| Playwright | 浏览器自动化核心 | 理论上可切换到 Puppeteer/Selenium |
