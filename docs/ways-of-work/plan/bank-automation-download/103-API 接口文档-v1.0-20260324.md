## 1. API 概述

### 1.1 基本信息

| 项目 | 说明 |
|------|------|
| **基础路径** | `/api/v1` |
| **认证方式** | JWT Bearer Token |
| **数据格式** | JSON (application/json) |
| **字符编码** | UTF-8 |
| **API 文档** | `/api/docs` (Swagger/OpenAPI) |

### 1.2 响应格式

#### 成功响应

```json
{
  "code": 0,
  "message": "success",
  "data": { },
  "timestamp": "2026-03-24T10:30:00.000Z"
}
```

#### 错误响应

```json
{
  "code": 1001,
  "message": "认证失败",
  "details": "JWT token 已过期",
  "timestamp": "2026-03-24T10:30:00.000Z"
}
```

#### 分页响应

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "items": [],
    "pagination": {
      "page": 1,
      "size": 20,
      "total": 100,
      "total_pages": 5
    }
  },
  "timestamp": "2026-03-24T10:30:00.000Z"
}
```

### 1.3 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 204 | 删除成功 (无返回内容) |
| 400 | 请求参数错误 |
| 401 | 未认证/认证失败 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 409 | 资源冲突 (如重复) |
| 422 | 数据验证失败 |
| 500 | 服务器内部错误 |

### 1.4 业务错误码

| 错误码 | 说明 |
|--------|------|
| 1001 | 认证失败 |
| 1002 | Token 过期 |
| 1003 | Token 无效 |
| 2001 | 组织不存在 |
| 2002 | 组织名称重复 |
| 3001 | 用户不存在 |
| 3002 | 用户名重复 |
| 3003 | 密码错误 |
| 4001 | 业务系统不存在 |
| 5001 | 流程不存在 |
| 6001 | 任务不存在 |
| 7001 | 文件不存在 |

## 2. 认证模块 (Auth)

### 2.1 用户登录

**请求**:
```http
POST /api/v1/auth/login
Content-Type: application/json
```

**请求体**:

{
  "org_id": 1,
  "username": "admin",
  "password": "password123"
}

  "message": "success",

## 10. 安全规范

### 10.1 认证要求

- 所有 API (除登录外) 都需要 Bearer Token 认证
- Token 通过 `Authorization` 头传递：`Authorization: Bearer {token}`
- Token 有效期 24 小时，支持刷新

### 10.2 权限控制

| 角色 | 组织管理 | 系统配置 | 流程配置 | 任务执行 | 文件查看 |
|------|----------|----------|----------|----------|----------|
| admin | ✅ | ✅ | ✅ | ✅ | ✅ |
| operator | ❌ | ❌ | ✅ | ✅ | ✅ |
| auditor | ❌ | ❌ | ✅ 查看 | ✅ 查看 | ✅ |

### 10.3 数据加密

- 凭证数据使用 AES-256 加密存储
- 密码使用 bcrypt 哈希
- 传输层使用 HTTPS

### 10.4 速率限制

| 端点 | 限制 |
|------|------|
| /api/v1/auth/login | 10 次/分钟 |
| /api/v1/tasks/execute | 5 次/分钟 |
| 其他端点 | 100 次/分钟 |
