## 🟠 P1 - 严重问题 (需要修复)

### FRONTEND-P1-001: Jest 测试配置问题 - @umijs/max Mock
- **状态**: ⚠️ 部分失败
- **描述**: 4 个测试套件失败，原因是无法 Mock @umijs/max 模块
- **影响**: 测试覆盖率只有 42.9%
- **失败测试**:
  - Login.test.tsx
  - Button.test.tsx
  - Input.test.tsx
  - request.test.ts
- **修复方案**:
  ```javascript
  // jest.config.js 添加 mock
  moduleNameMapper: {
    '^@umijs/max$': '<rootDir>/__mocks__/@umijs/max.js',
  }
  ```
- **预计工时**: 2 小时
- **负责人**: Developer C

### FRONTEND-P1-002: 业务系统表单 Input.Select 组件不存在
- **状态**: ⚠️ 需修复
- **描述**: System/index.tsx 中使用了不存在的 Input.Select 组件
- **影响**: 业务系统创建/编辑页面无法正常工作
- **修复代码**:
  ```tsx

  // 正确写法
  <Select>...</Select>
  // 需要从 antd 导入 Select 组件
  import { Select } from 'antd';
  ```
- **预计工时**: 0.5 小时

- **状态**: ⚠️ 需修复
- **描述**: Button.test.tsx 和 Input.test.tsx 无法找到对应组件
