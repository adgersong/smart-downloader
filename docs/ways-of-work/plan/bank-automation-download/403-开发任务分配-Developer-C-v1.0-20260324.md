## 3. 技术规范

### 3.1 代码规范

- 使用 TypeScript
- 遵循 ESLint + Prettier 规范
- 组件使用函数式 + Hooks
- 单个组件不超过 200 行

### 3.2 组件规范

```tsx
// 组件必须使用 TypeScript
interface Props {
  name: string;
  age?: number;
}

export const MyComponent: React.FC<Props> = ({ name, age }) => {
  return <div>{name}</div>;
};
```

### 3.3 Git 提交规范

```
feat: 新功能
fix: Bug 修复
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具链相关
```
